# SenseHome 家庭约定与设备边界知识库（AgentArts RAG 语料）

- **文档版本**：`2026.11`
- **适用平台**：华为云 AgentArts（智果）知识库（建议按二级标题 `##` 分段，开启规则编号精确召回）
- **安全边界声明**：本知识库仅用于解释家庭成员个性化约定与场景规则；**设备实时状态必须通过只读工具或 MCP 实时查询**，强制权限与执行确认由 SenseHome 边缘网关实施。

---

## RULE-001：日常离家灯光检查范围

- **规则编号**：`RULE-001`
- **类别**：`leave_home`
- **适用房间**：书房、阳台、厨房、卫生间、卧室、门口、客厅
- **规则内容**：
  1. 当用户表达离家/出门意图且未指定单一房间时，默认巡检全屋已授权灯光（`kind = light` 且 `access = control`）。
  2. 必须逐一读取实时状态：仅对当前状态为 `on`（开启）的灯生成 `light.turn_off` 动作。
  3. 当前状态为 `off`（关闭）的灯不得列入拟执行动作，应归入检查单 `skipped`（自动跳过）列表，并由边缘网关纳入确认前状态依赖监控。
  4. 若检查范围内存在设备离线、状态为 `unknown` 或 `unavailable`，禁止猜测或忽略，必须返回 `clarification` 提示用户核实。
- **例外条款**：若命中 `RULE-002`（室友/家人在场或口语明确排除某房间/设备），则先排除对应房间或设备后再执行筛选。

## RULE-002：客厅有人与家庭成员保留例外

- **规则编号**：`RULE-002`
- **类别**：`leave_home`
- **适用房间**：客厅（及用户口语明确声明有人/保留的任意房间）
- **规则内容**：
  1. 当用户提到“室友还在客厅”“家人在客厅”“客厅别动”“不要动客厅”或“除了客厅”时，必须完整保留 `light.living`（客厅顶灯）与 `climate.living`（客厅空调）。
  2. 保留设备不得出现在 `actions` 数组中，必须明确写入检查单 `preserved` 列表并标注 `rule_id: "RULE-002"`。
  3. 若用户指定排除其他房间（如“卧室别动”“阳台灯留着”），同样写入 `preserved` 列表，严禁生成该房间内任何控制动作。

## RULE-003：入户门磁与环境传感器只读核查

- **规则编号**：`RULE-003`
- **类别**：`inspection`
- **适用设备**：`binary_sensor.front_door`（入户门磁）、`sensor.living_temperature`（客厅温度）、`camera.front_door`（门口监控）
- **规则内容**：
  1. 离家场景默认附带读取 `binary_sensor.front_door`（入户门磁）实时状态；`state = on` 表示“打开（未关闭）”，`state = off` 表示“已关闭”。
  2. 所有只读观测结果必须附带采样时间戳 `last_updated`；当传感器离线或状态为 `unknown` / `unavailable` 时，明确提示“无法核实，请人工确认”。
  3. 门磁、温湿度传感器与摄像头属于 `read_only` / `event_only` 设备，**严禁对其生成任何控制动作**；摄像头仅返回在线状态，严禁上传或分析画面。

## RULE-004：书房阅读场景与模糊意图澄清约定

- **规则编号**：`RULE-004`
- **类别**：`scene`
- **适用房间**：书房
- **规则内容**：
  1. 当用户明确说明“我想在书房看书 / 开启书房阅读模式”时，可建议组合动作：将 `light.reading`（书房阅读灯）设为 `brightness_pct: 40`，并拉开 `cover.study`（书房窗帘）。
  2. 当用户仅说“我想看书 / 我要阅读”且未指明房间时，**必须返回 `clarification`** 追问所在房间，严禁擅自猜测为书房或卧室。

## RULE-005：否定句式与越权控制硬红线

- **规则编号**：`RULE-005`
- **类别**：`safety`
- **适用范围**：全屋所有实体
- **规则内容**：
  1. 凡包含直接否定指令（如“不要打开阅读灯”“别关客厅灯”“取消操作”）时，必须返回 `clarification`（空动作列表），严禁剥离否定词执行反向或正向动作。
  2. 云端智能体只拥有“查询（Read）”与“提案（Propose）”权限，永远不得声称“已执行”或尝试绕过人工确认。
  3. 任何未在设备目录中登记的实体、离线实体、或超参数范围（亮度不在 0..100、温度超出 `min_temp..max_temp` 或不符合步长）的动作均会被边缘护栏硬拒绝。

## RULE-006：隐私分级本地旁路策略

- **规则编号**：`RULE-006`
- **类别**：`privacy`
- **适用范围**：全屋
- **规则内容**：
  1. 凡用户指令包含“不要上传 / 禁止上传 / 仅在本地 / 不要联网 / 离线运行”等隐私限定词时，SenseHome 边缘网关直接拦截，不向华为云 AgentArts 发送请求文本、设备目录或状态快照。
  2. 非侵入式 Wi-Fi CSI 原始 IQ 数据永远留在边缘本地，仅允许将脱敏后的窗口分类摘要（运动 / 静止 / 缺测）用于本地复核或只读展示。

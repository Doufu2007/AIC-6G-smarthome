## 主要结果

合成 replay 的 `interactive_inference` 结果如下。时限达标要求完成固定规划合同且在配置的时限内；合同未完成或超时均计为未达标。该指标不等同于自然语言理解准确率。

| 策略臂 | n | 完成合同且满足时限 |
|---|---:|---:|
| 双端联合 `joint` | 5,040 | 84.40%（4,254/5,040） |
| 仅网络 `network-only` | 5,040 | 62.98% |
| 仅算力 `compute-only` | 5,040 | 61.90% |
| 无迟滞 `no-hysteresis` | 5,040 | 84.52% |

联合策略仍有 786 条 `UNRESOLVED_NO_NLU`。无迟滞臂的时限达标率略高，因此数据不支持“迟滞提升达标率”；指定合成轨迹中，联合策略发生 93 次路由切换，无迟滞臂为 207 次，只能说明该轨迹上的切换次数不同，不能据此声称用户体验或总体可靠性收益。独立 HTTP 实验的矩阵复杂任务中 joint/network-only 时限达标率为 80.95%/61.90%；HTTP 压力组为 52.98%/52.54%，两组均是各自的本机墙钟结果，不能与合成 replay 混算。

HTTP 网关桩实验包含 2,940 条矩阵请求和 6,144 条压力请求。679 条合同未完成，其中 383 条为 `CONTRACT_NOT_COMPLETED`，296 条为实验注入的下游 `HTTP_503`；9,084 个外层 HTTP 响应状态均为 200。注入的 503 是应用层故障场景，不是实际网络丢包。283 项 HTTP SHA256 清单均匹配。

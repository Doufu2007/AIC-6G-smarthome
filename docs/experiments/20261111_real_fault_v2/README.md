# 真实模型与受控HTTP代理：2026-11-11新一轮

本轮按注册方案只执行一次。原生产策略、提示词、动作保护、20条人工冻结标签与旧600行记录均未改动。这里新增120条受控回归记录；不能与旧记录合算“准确率”或实际部署可靠性。

## 已完成与计数

- 2条旧人工复杂命令C01/C04 × 4臂 × 3重复 × 5条件 = 120行，30个四臂配对块；0跳过、0运行器异常。
- 主矩阵120次客户端到代理POST中，102次确实转发至真实模型，102次上游HTTP200；18次为代理实际返回503，没有调用模型。不能称120次真实模型推理。
- 每条件两次预热，共10次代理POST，8次实际转发，另列于各`warmups.json`；不算进120行。
- 配对观测含60次模型清单GET和60次代理遥测GET，最初两次原模型清单探测另存`upstream_probe.json`。
- `audit.json`记录作者离线核验通过；新代理4项行为测试先RED后GREEN，与冻结运行器16项合跑20项通过，日志`test_results.log`。测试夹具没有计为真实模型。

结果逐条件见`summary.md`与`summary.json`，每行保留模型原文、动作、前后状态、传输和保护/回退结果。

## 结果与适用范围

每条件每臂6个非空任务。健康条件四臂均6/6；cloud代理503时固定cloud为0/6，其余6/6；local代理503时固定local与仅网络为0/6，联合和固定cloud均6/6。失败路径约5ms的快速返回不解释为成功时延优势。

local固定700ms准入等待时，联合全部完成，中位1042.006ms；仅网络1431.163ms、固定local1420.246ms、固定cloud1046.806ms。cloud等待条件下联合和仅网络都选择local，完成情况相同；不能把此条件说成联合独有收益。正常健康中位差只作描述，不宣称稳定优越或统计显著。

这里的503是自建代理实际HTTP响应，底层模型服务始终保持运行；700ms是在代理内实际等待并测量的固定准入门控时间，`/health`报告最近样本及样本年龄。它不是GPU真实队列、竞争工作负载、真实服务崩溃、真实WAN故障或6G空口实验。两模型依旧共享同一电脑和GPU，设备为隔离JSON模拟。

这组数据支持“在已知的受控HTTP准入失败/等待条件下，算力观测可使现有C策略切换到另一个模型候选”的软件行为结论；不支持真实家庭业务收益、真实用户泛化、独立云边或总体可用性数字。两条命令是有意选用已验证的人工回归用例，用于隔离路由而非扩大语言能力结论。

## 预注册与状态控制

注册在`registration.json`，早于任何本轮模型预热与正式推理，锁定数据、校准、配置和12项源码/二进制哈希；注册/运行器自身已保存快照。五条件顺序固定；每条件独立创建4个C策略进程，条件间恢复计数清零，条件内同臂连续3重复，设备状态每次重置。四臂共享同一命令、上下文、初始状态和配对健康观测，臂顺序轮换。

延迟固定700ms，没有依据结果加大或重跑。local/cloud推理代价固定复用旧校准1116/1361ms，非本轮重拟合。新服务由主线单独启动在63452/63454，服务别名仍为Qwen2.5-1.5B-Instruct-Q4_K_M和Qwen3-4B-Q4_K_M；大模型本轮增加显式`--reasoning-budget 0`，与旧轮环境分开披露，不据此覆盖旧模型结果。详细运行时和权重身份由主线环境清单记录。

## 审查入口

1. `registration.json`：先注册规则、哈希、case、重复数、条件、恢复状态和计分口径。
2. `conditions/*/report.gateway_raw.json`：冻结运行器首次写出的报告；`report.json`仅追加透明代理调用计数和边界，原始报告未覆盖。
3. `conditions/*/rows.jsonl`及`blocks.jsonl`：逐行及配对观测；`proxy_records.json`保存代理实际HTTP原文、等待、是否转发、真实模型原文及唯一trace。
4. `conditions/*/source_snapshot/`：冻结运行器调用的11份源码/二进制；顶层`source_snapshot/`另含本轮代理运行器。
5. `verify_run.py`：只读复算逐行评分、摘要、配对、trace去重、主矩阵/预热分离、等待样本、注册先后与哈希。执行`python docs/experiments/20261111_real_fault_v2/verify_run.py`，不发任何模型请求。

`legacy model_calls`字段继承运行器定义，在本实验中表示客户端到代理的POST尝试；准确模型量必须读`actual_upstream_model_post_attempts`。输出目录已有原始行时运行器拒绝重跑。模型生命周期由主线管理，本运行器仅关闭自有代理和C子进程，不停止模型服务。

开始前，先了解会保存什么

运行任务时，命令、模型响应、软件状态和耗时会立即写入本次私有运行目录；需求回答和反馈只有最后确认保存才写入记录文件。不录音、不录像，不记录IP、姓名、联系方式或住址。请勿填写个人身份信息。

每次启动只接待一人。取消、撤回或未保存就关闭服务，会先停止本次网关、模型和软件设备，再删除本次私有运行目录及反馈。删除是普通文件删除，不能保证覆盖磁盘历史数据。已保存后仍可在本会话撤回。

未勾选同意时不会创建记录。采集模式由操作者启动服务时设置，不能在此页改成“真实用户”。

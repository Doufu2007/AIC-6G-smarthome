# 来源与版本清单

## 历史资料和验证边界

本机工作区保留 AIC 最终提交包及官方手册原件，未放入本仓库当前版本。历史提交、AIC 参赛编号、旧方案/答辩文件和旧证据对应其当时的项目版本，不代表本次华为 ICT 项目的现状。

v11 自动化测试是软件回归测试，不代表真实家庭试点。历史 Home Assistant 证据涉及虚拟实体；历史模型和网络测试须按原始版本、设备条件和数据集范围引用。实体家电、独立外部用户以及 6G 实网效果仍需分别验证。

## 源码取得

- openvela 基础代码来自 `openvela_smart_home` 项目资料中的源代码副本。
- Python Runtime 源码来自 SenseHome-6G v11 工作目录，保留 `v11/` 与同级 `ai6g_runtime/` 依赖结构。
- 华为 MaaS API 地址、认证和模型 ID 依据华为云官方文档。实际调用仍以账号控制台当前可用区域、模型和配额为准。

本文件只说明目录来源和范围，不将旧项目成绩归入当前项目。

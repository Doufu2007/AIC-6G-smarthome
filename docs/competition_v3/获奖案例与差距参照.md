# 与可核实全国一等奖作品的差距参照

核对日期：2026年11月11日。用于确定改进优先级，不用于预测获奖概率。来源、逐字短引、原始行位置与SHA256见同目录`award_sources.json`和`award_excerpts/`；完整网页仅保存在忽略的`.firecrawl/v3-*`，不将临时附件链接或整页导航纳入提交件。

## 1. 没有可供回溯的本专项赛国一作品

赛事官方页标题明确为“首届人工智能+6G青年创新创业专项赛”；赛程为11月13日20:00截止，11月14至15日形式审查、11月16至20日复赛，决赛安排在11月底至12月中上旬。以本次核对日期11月11日，不能将同届尚未产生的全国一等奖作品说成已知标杆，更不存在本专项赛前几届的国一经验数据。

官方同时允许提交“已落地实施的应用场景解决方案”或“面向实际需求的应用场景设计方案”。因此，没有硬件并不构成自动失格；但设计方案仍需证明需求来源、技术可执行性与推广价值，不能用硬件缺失作为不验证软件的理由。

**来源S0**：[官方赛题页](https://www.aicomp.cn/tracks/tracks-4/5322.html)。以下四个案例来自其他赛事，比较的是项目形成可信说服力的方式，不是本赛评分标准、同条件基线或国一充分条件。

## 4. 当前差距最大的不是材料数量

当前v2已经有C策略、动作合同、隔离状态、四组600行封存记录、120行HTTP故障补证、用量核算与完整材料。其强项是保留失败、区分模型响应与业务完成、原始证据可复算。这些高校新闻通常不公开同等粒度数据，因而不能说SenseHome在所有技术维度均落后，也不能仅凭自家日志多就判定更强。

以下是依现有v2事实作的工程判断，**不是官方分数或获奖概率**。

|---|---|---|---|---|
| 主场景 | 泛称“家庭AI控制/存量住宅集成商”；外部反馈0 | 具体岗位、一次操作和失败后果没有形成项目自己的证据链 | 一个主用户角色、一条端到端任务、一个明确故障后果；目标来自真实反馈或明确标为设计假设 | 可先收窄场景并重写交互/演示；真实反馈必须等自愿真人 |

## 5. 建议优先补的五件事

1. **先形成唯一可操作入口与本轮演示**。复用生产网关和真实模型，不为了演示另写成功逻辑。输入任务后同时呈现候选健康、路由理由、允许动作、执行状态与trace；无模型就如实标不可用。把旧视频保留为历史，用新日期录制本轮真实软件过程。
2. **补强最有竞争力的简单基线**。固定第二模型在当前留出24/24，优于joint21/24；必须让评委看到这条事实。健康回退策略也是合理替代。新实验预注册、新目录、新版本，不用旧留出失败调参数，也不把事后最优选取伪装成真实可部署算法。
3. **把主张收敛到已经可证实的机制**。“在部分模型不可用或准入等待增加时选择另一候选，并用统一动作合同约束执行”有证据；“全国领先6G智能家居”“正常条件普遍更快更准”无证据。对照需要解决的是简单策略何时不足，而非让joint对所有条件都赢。
4. **补面向真实适配的合同**。设备接口、幂等ID、确认/超时、失败不部分执行、重试副作用和状态新鲜度应能说明。协议模拟器能先测接线，必须与物理设备确认分开。
5. **准备外部事实一到即可落盘的验收**。用户试用、授权设备、独立网络、成本账本均已有工具或可完善；在条件出现前保持0/null/待验收。用真实的“不知道”“失败”“不愿意用”指导选题，比编写正面证言有价值。

## 6. 不能从获奖新闻推出“国一全部条件”

案例能显示作品完整度、问题聚焦、通信/设备角色和现场呈现的重要性，但无法恢复评委打分过程。新闻是经过筛选的成功报道，没有同场未获奖作品、分项分数、原始对照数据与评委权重，存在明显幸存者偏差。不能据此给出“已达到国一的85%”“再加一个硬件就稳拿”等数字。

国一仍是相对竞争：即使补齐所有正式材料与工程验收，也还要看同届参赛质量、现场答辩和评审。本轮能够给出的是逐项证据与行动，不是确定奖项。

# 正式执行通道与持久命令

正式网关已接入持久回执适配器。实际本机MQTT服务、客户端与SQLite软件实体完成六类故障核验，均PASS；逐项记录见佐证。

接口结构：动作合同通过后写入command_id、规范payload摘要、平台身份、逐动作目标和待确认状态；适配器发送；接收回执或回查；数据库记录确认、部分或未知。相同ID且payload不同必须冲突。

| 字段或状态 | 核验作用 |

| --- | --- |

| command_id / payload_hash | 将重试与新命令区分；阻止ID复用混淆 |

| platform identity / action identity | 拒绝来源、设备或动作不匹配的回执 |

| submitted / confirmed / partial / unknown | 避免把提交成功解释为全部完成 |

| SQLite与事件 | 跨网关进程保存待确认记录并回查 |

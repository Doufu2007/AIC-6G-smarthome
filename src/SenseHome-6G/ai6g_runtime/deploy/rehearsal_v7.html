现场审验顺序

  1. 预览组合合同，核对地点、设备和参数。
  2. 执行，右侧核对实际状态。
  3. 保持 ID 再执行，检查幂等重放。
  4. 保持 ID 修改文本，检查冲突拒绝。
  5. 新 ID 输入定时或未知动作，检查零动作澄清。
